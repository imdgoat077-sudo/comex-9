Key research papers on multi-agent orchestration:

#### Foundational Frameworks & Dynamic Orchestration
* [AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation](https://arxiv.org/abs/2308.08155)
  * **Authors:** Qingyun Wu, Gagan Bansal, Jieyu Zhang, et al.
  * **Core Idea:** Introduces a multi-agent conversation framework where customizable, conversable agents interact through automated chat flows to solve tasks collaboratively.
* [ChatDev: Communicative Agents for Software Development](https://arxiv.org/abs/2307.07924)
  * **Authors:** Chen Qian, Xin Cong, Cheng Yang, et al.
  * **Core Idea:** Orchestrates specialized agents (designer, programmer, tester, reviewer) across waterfall-phase communication chains with chat-chain verification loops.
* [WorkflowOps: Learning Agent Collaboration Priors for Multi-Agent Workflow Orchestration](https://arxiv.org/abs/2610.07860)
  * **Authors:** Qi Cheng, Shengyu Chen, Wei Cheng, Zhengzhang Chen, et al.
  * **Core Idea:** Learns collaboration priors across agent topologies to optimize execution flows, reduce coordination overhead, and automate agent role handoffs.

#### Adaptive & Competence-Aware Routing
* [Competence-Aware Orchestration for LLM-Based Multi-Agent Systems](https://arxiv.org/abs/2610.13144)
  * **Authors:** Songmiao Wang, Yuchen Wang, Chenglin Yu, Hongxia Yang, Ming Li
  * **Core Idea:** Dynamically routes queries and alters the interaction graph based on the model's query-level competence, cutting token cost by over 36% while improving reasoning accuracy.
* [MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework](https://arxiv.org/abs/2308.00352)
  * **Authors:** Sirui Hong, Mingchen Zhuge, Jonathan Chen, et al.
  * **Core Idea:** Encodes Standard Operating Procedures (SOPs) into structured prompt schemas and message-broker architectures to prevent cascading errors in large collaborative agent setups.

#### Topology, Diagnosis, & Reliability
* [Know the Shape, Find the Fault: Topology-Conditioned Diagnosis of Multi-Agent LLM Failures](https://arxiv.org/abs/2610.10126)
  * **Authors:** Xinwen Liu, Zhuocheng Pan, Isabella Zhu, Jawei Zhang, et al.
  * **Core Idea:** Introduces MAScope, mapping communication topologies from multi-agent execution traces to classify orchestration bottlenecks and coordination failures at reduced diagnosis cost.
* [More Agents Is All You Need](https://arxiv.org/abs/2402.05120)
  * **Authors:** Junyou Li, Qin Zhang, Yanghua Xiao, et al.
  * **Core Idea:** Analyzes scaling properties of multi-agent ensembles, demonstrating when simple voting vs. hierarchical orchestration scales performance across diverse benchmarks.
